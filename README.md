# Sistema de Gestión de Inventario

Proyecto final desarrollado para la asignatura **Electiva I**.

Este sistema permite gestionar el acceso de usuarios mediante autenticación y roles, diferenciando entre usuarios administradores y usuarios operadores. La aplicación cuenta con vistas de inicio de sesión, registro y panel principal para la administración del sistema.

## Funcionalidades Principales

- Inicio de sesión de usuarios.
- Registro de nuevos usuarios.
- Asignación de rol de usuario operador al registrarse.
- Acceso diferenciado según el rol del usuario.
- Panel principal para visualizar información general del sistema.
- Protección de rutas mediante autenticación.

## Roles del Sistema

### Administrador

El usuario administrador tiene permisos para acceder a las funcionalidades principales del sistema y gestionar la información correspondiente.

## Credenciales de Acceso

### Credenciales de Administrador

Estas credenciales permiten ingresar al sistema con permisos de administrador.

- **Usuario:** `admin`
- **Contraseña:** `admin123`

### Credenciales de Usuario

Estas credenciales permiten ingresar al sistema con el rol de usuario u operador.

- **Usuario:** `usuario`
- **Contraseña:** `usuario1234567`
